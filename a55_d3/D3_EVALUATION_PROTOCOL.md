# D3 评估协议

## 数据与边界

D2 冻结 1117 族为主范围，原始表、概念 ID、归并、D1/E3 输入只读。D3 独立版本，不添加新采集或向量。当前语义模型按用户最新要求使用官方 `deepseek-flash`，替代任务包中默认本地 Qwen 的建议；D2 原始 Qwen 结果仍是归档基线。

## 冻结抽样

随机种子 20261027。140 个唯一族：98 development、42 holdout。按 D2 11 个来源队列及摘要存在性分层，样本标签是抽样代理，不是技术真值。开发集含有明确记录的已知风险优先样本，其余为固定种子抽样。Holdout 排除本对话已知问题及历史 45 族。抽样时只读取历史 ID 排除重叠，不向主抽取提供历史名称/答案。

首次模型调用前元数据隔离检查发现 6 个开发族与历史组重叠，已按同队列、摘要存在性和代理类别替换；原锁与更改理由保留在 SPLIT_PRECALL_AMENDMENT。42 个 holdout 不变。所有 140 个族和历史组不重叠。

Holdout 正文在提示词调试期间不向开发者展示，也不运行抽取或评估。通过 MODEL_FREEZE 记录提示词、Schema、语义代码哈希和 Git commit 后，执行一次预定配置评估。主版本复用同指纹缓存，不再次生成盲测结果，不根据盲测结果修改语义提示词。确定性导出和汇总程序可后续修复，不能改语义生成。

## 实验范围

1. 约30开发族先检查结构、引用、运行行为及多贡献偏向。
2. 98开发族执行完整流程；30族固定消融子集比较全部配置，其他开发族至少比较归档D2与完整D3。
3. 冻结后42 holdout执行同配置消融。D2原始归档与D2提示词在DeepSeek上的复演分别标记，不能把换模型收益归到提示词。
4. 最终主版本覆盖现有1117族；D2失败族也尝试并单独记录，失败/待复核/弃判分开。
5. 历史45族在主语义版本冻结后专项回归；39原发现与6探针分别统计，不混入独立指标。

消融配置为：D2归档；D2精确prompt/schema/source-ID传输及2200输出上限的DeepSeek复演（后端/分词器不同，不称相同Qwen流程）；仅改贡献组织；两阶段抽取与要素保真；加独立原文证据审核及修订；完整D3增加双轴相关性。后两项的贡献文本相同，额外改动仅在相关性，不伪称另一个贡献抽取实验。

## 审核标准

审核维度：对象、问题、机制、材料、工艺方法、顺序、参数、效果、多贡献、虚构、来源充分性；另有喷头应用证据A轴和工程关联B轴。

- Correct：该维度的主要技术事实完整、正确且由原文支持。
- Partially Correct：核心成立但有重要遗漏或限定丢失。
- Incorrect：关键事实错误、关系错配、严重遗漏或无依据结论。
- Insufficient Source Evidence：Title/Abstract没有足够信息，不能算模型应恢复细节的错误，也不能算正确。
- Uncertain：审核者无法判定，排除可判定准确率分母并单列。

所有当前模型审核为 Silver；人工列初始留空，只有真实独立人员审核后才能标Gold并填写人员、时间和理由。原D2中Codex参与的修订也是AI，不是人工Gold。没有人工数据时所有Gold准确率明确N/A；可继续工程和自动诊断。

## 三层证据

L1：source ID映射原始title/abstract Unicode码点[start,end)，每一片段逐字回读一致；绝不把L1当语义质量。
L2：每个非空字段/结构化记录单独六级审核，审核必须重新读取完整原文。
L3：贡献组合的实体—关系—对象结论审核，特别检查工艺实际对象、靶/膜、阶段、联合窗口、测量/制造混淆。

等级 Explicit、Supported Paraphrase、Partial、Inferred、Unsupported、Insufficient。只有前两级可标为模型审核支持的候选事实，仍非人工确认事实。原始抽取与审计、修订、二次审计、采纳理由分别保存；未解决的争议隔离，不通过删除所有技术手段来假装通过。

## 指标与分母

每项输出 numerator、denominator、split、configuration、label_tier、sample_n、unknown_n、来源。无适用信息与未知不记为0正确。

- 技术维度Silver正确率：Correct / {Correct,Partially Correct,Incorrect}；另列部分正确、来源不足与不确定数。
- 正确贡献覆盖：审核认为正确贡献数 / 原文可评估的应有贡献数；无法判数排除，不能只看贡献数上升。
- 误拆分、虚构贡献：审核判定数量 / 实际输出贡献数量，来源不足与弃判另列。
- 多贡献遗漏：应有贡献>1且有遗漏的族数 / 应有贡献>1的可判定族数。
- 要素保真：审核保留的关键材料/工艺项 / 同一来源可评估的关键项；为Silver参考而非Gold召回率。
- L1一致率：逐字段证据引用通过数 / 总引用数；L2支持率：前两级字段数 / 全部有审核的非空字段数；L3独立列出。
- 平均贡献数：明确贡献条数 / 尝试族数；失败不能伪作弃判；另列有效族均值。
- 喷头漏/误判：以重新读原文的独立Silver复审为参考，分A轴明确应用/制造与B轴直接/制造/工程迁移分别计算。旧单标签不等同双轴；不能简单把Transferable当A1。争议记录隔离并保留。
- 费用：实际usage累计，按官方公布峰时单价给保守上界估算；不是账户账单。无usage的网络失败费用未知，不编0。D2本地调用没有云账单，不能虚造美元成本。

同模型Silver审核可能存在相关性偏差；匿名顺序随机化不消除同模型偏差。没有人工Gold时不能据此断言真实质量已被独立证明。D4工程可用性与D5扩大规模准入分别给出有条件结论。

## 人工审核入口与导入

人工工作簿提供Human_*判定、审核者、时间、理由以及原文/版本。导入必须核对family_id、split、source_text_hash和允许枚举；未填字段保留空，不从Silver回填。人工结论与模型结果分表、记录来源；若修改主技术事实，必须新版本并保存证据与修改人。
